# 📚 AI Study App

An intelligent mobile application built using **Flutter** that helps students organize and improve their study experience using modern technologies.

The app provides a clean and user-friendly interface based on a Figma design, along with authentication and onboarding features.

---

## 🚀 Features

* 🔐 Authentication system (Login / Signup)
* ✅ Form Validation
* 🔥 Firebase Integration
* 👤 User Profile Screen
* 📖 Onboarding Screens
* 🏠 Home Screen
* 🧭 Navigation System
* 💬 AI Chat Screen (UI Ready)

---

## 🛠️ Tech Stack

* Flutter
* Dart
* Firebase Authentication
* Shared Preferences
* Figma (UI Design)

## ⚙️ Setup & Run

1. Clone the repository:

```bash
git clone https://github.com/demiana25/EduMind-Flutter-project.git
```

2. Navigate to the project folder:

```bash
cd ai_study_app
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the app:

```bash
flutter run
```
